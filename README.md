# Sorting_Manipulator
Manipulator umieszczony obok pola roboczego sortujący przedmioty. Wykrywanie obecności przedmiotów ma odbywać się poprzez system wizyjny w postaci kamerki. Wykrywanie kolorów ma odbywać się poprzez spektrofotometr doprowadzony na końcówkę efektora. Po wykryciu i identyfikacji przedmiotu ma nastąpić przełożenie go w odpowiednie miejsce.
